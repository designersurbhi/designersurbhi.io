Problem solving

A clear path from ambiguity to interface decisions.

Surbhi's strongest pattern is implementation-aware design: understand the business rules, shape the workflow, test the interaction model, and prepare clear handoff for delivery.

1

Frame the problem

Clarify stakeholder goals, user tasks, constraints, and the workflow moments where users need the most guidance.

2

Map the experience

Translate requirements into user journeys, information architecture, wireframes, and screen states.

3

Prototype the system

Explore interaction patterns, reusable components, responsive behavior, and handoff details before implementation.

4

Iterate with teams

Use design reviews and cross-functional feedback to refine the product while balancing user needs and technical constraints.
